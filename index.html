Ethics by design

Moral values, safety rules and ethical principles are built directly into the architecture, from the very first phase of development.

The system does not kill; it observes.

The system does not lie: if its confidence level is below 0.85, it answers “I don't know.”

The system does not steal: it stays offline, local and sovereign.

Five verifiable requirements

Each requirement is formulated so that it can be tested.

Non-harm

No offensive function; observation is the default behaviour.

Truthfulness

Below the 0.85 confidence threshold, the system abstains.

Sovereignty

Inference and storage stay local; no network required.

Human control

Every sensitive action requires human validation.

Memory integrity

History is sealed; any alteration is detectable.

Two cross-cutting mechanisms

Below the threshold, the system abstains whatever the colour. Above it, the colour decides — human intervention remains the last link for any sensitive decision.

● GreenAllowed. The action runs or the content is displayed.
● OrangeValidation required before execution.
● RedForbidden. The action is blocked.
