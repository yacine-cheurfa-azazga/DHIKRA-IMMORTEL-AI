DHIKRA QUAD SYSTEM AI

Offline deterministic inference kernel with explicit abstention

Technical Report TR-2026-QUAD-0018, Version 2.4, public showcase

Zenodo v2.4 CC BY-NC-ND 4.0 ORCID 0009-0005-1982-7176

Abstract

DHIKRA QUAD SYSTEM AI is the public showcase of the QUAD SYSTEM AI architecture (TR-2026-QUAD-0018, v2.4). It describes an ethical, deterministic, offline artificial intelligence system designed to operate in a disconnected local environment, with no cloud dependency and no online learning.

The system relies on an inference kernel based on validated rules, with three core properties.

Determinism
Given identical inputs, software version, configuration and rule set, the system produces identical, reproducible results.
Explicit abstention
If the certainty score C(x) is below the threshold τ = 0.85, the system returns an explicit abstention message and no substantive answer. The threshold is an uncalibrated design choice: it must be set from a risk-coverage analysis on a held-out labelled set. Abstention limits unjustified answers; it does not make the answers given correct.
Sealed memory
Validated entries are append-only and chained by cryptographic hash. Any modification of an entry invalidates the subsequent chain, which allows tampering to be detected without guaranteeing confidentiality. Temporary session data is kept separately and purged on request.

The kernel source code, full protocols, detailed formulas, exact inference rules and internal documentation are confidential and unpublished. This showcase provides only the public specification and the proof of dating. No certification, regulatory approval, formal verification or performance is claimed in this version.

The four quadrants

Cross-cutting design axes, applied to the kernel and to each module, independently of the number of modules.

Q1 Source

Values, intent, sealed memory and the RAHMA (رحمة) cultural alignment protocol. It defines why the system acts, which values it respects and which memory it protects.

Q2 Logic

Local, offline language model. It handles text, then the plan, then execution instructions. Validated by the MICAE approach, and operates without an Internet connection.

Q3 Vision

Predictive modelling of the real world with V-JEPA 2-type latent embeddings. It anticipates states from t+1 to t+3 before any action.

Q4 Action

Kinematic control of a robotic arm (Franka). Execution depends on ILM tablet validations and is sealed through the CCSS protocol. No physical action runs without validation.

The learned components (Q2, Q3, Q4) fall outside the scope of the deterministic claims of this document. Determinism is specified only for the rule-based kernel.

The five elements

  • SOURCE DHIKRAKernel and parent application. Offline deterministic inference, sealed memory, Respect-Check protocol. No cloud dependency, no online learning, verifiable decisions. Specifications published, kernel unpublished.
  • SAHA SCAN AILocal reading of food labels, analysed offline with a three-colour classification (green, orange, red). When uncertain, it answers “I don’t know”. For information only; it does not replace medical or nutritional advice.
  • ILM LIBERATION TABLETOffline single-application tablet with no phone chip and no sound. Network access is limited to institutional Wi-Fi. Designed for closed institutional networks. POC reference: ILM-TABLET-2626-POC.
  • TAFSUT AICivil humanitarian drone with no offensive function and on-board processing. Regulatory compliance is required before any deployment. Design specification.
  • TUDERT YIWENFormerly THUDERT 1. Veterinary decision support in Kabyle, Arabic and French. It does not replace a veterinarian and requires field validation. Design specification.

Governance and validation

  • CCSSSecure Control, Certification and Sealing. Sealing by cryptographic fingerprints. Action orders are certified by the Respect-Check ethical filter and by human validators. Decisions of the orchestration kernel stay traceable.
  • MICAEA memory entry is valid only when the human, animal and environmental validators agree. SOURCE DHIKRA then seals it.
  • ConsentLocal community decision. Municipal council approval is mandatory for any critical use. The right of objection is guaranteed before a place of memory is sealed.
  • Respect-CheckColour-coded ethical control for action orders and memory entries. Green: execution possible. Orange: review required. Red: blocked.

Limitations

  • Determinism is specified only for the rule-based kernel.
  • No formal verification has been performed.
  • The security properties require an explicit threat model and independent testing.
  • Regulatory compliance (civil drone, food and veterinary information) has not been assessed.
  • No certification is claimed.
  • Abstention reduces unjustified answers but does not guarantee the correctness of the answers provided.
